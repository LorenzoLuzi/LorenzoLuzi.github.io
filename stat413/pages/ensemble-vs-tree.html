One Tree vs Bagging vs Random Forest

This applet shows a normal decision tree vs a bagging ensemble vs a random forest (\(m=1\)). There are multiple datasets for the classification task so that you can see the difference. You can modify the number of trees in the ensembles, the depth of each tree, and the minimum points per leaf node before stopping.

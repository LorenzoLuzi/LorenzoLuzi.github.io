DBSCAN: Density-Based Spatial Clustering of Applications with Noise

The algorithm

  1. Find the points which are \(\epsilon\)-neightbors of each other. That is, \(\mathbf x\) is an \(\epsilon\)-neightbor of \(\mathbf y\) if \(\|\mathbf x - \mathbf y\|_2 < \epsilon\)
  2. Mark all points which have more than \(n_c\) neighbors as core points
  3. Find the connected components of the core points. This tells you the number of clusters \(K\).
  4. For non-core points, assign it to a nearest cluster if the cluster is an \(\epsilon\)-neighbor
  5. Any leftover points are outliers

\(\varepsilon\): 0.30 \(n_c\): 4
